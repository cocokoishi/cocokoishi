### Unity / VRChat Tools

- **[AvatarObfuscator](https://github.com/cocokoishi/AvatarObfuscator)** – Obfuscates avatar parameter names to frustrate anyone trying to steal your model. Combine it with an OSC password lock to make ripping painfully expensive.

- **[udon-serialized-variable-editor](https://github.com/cocokoishi/udon-serialized-variable-editor)**  – A wildly hacky script built entirely on reflection. - **[unity-blendshape-to-json](https://github.com/cocokoishi/unity-blendshape-to-json)** – Companion tool for VRCALoader; exports blendshapes to JSON.

- **[vrchat-drawing-script](https://github.com/cocokoishi/vrchat-drawing-script)** – A fun drawing script for VRChat.

- **[MenuFXLockPicker](https://github.com/cocokoishi/MenuFXLockPicker)** – VRC avatar menu password lock parser. I figured out that identifying passwords by their structure was obvious long before I built the obfuscator. 本意是好的，ai执行歪了。
